# 变电安全题库（GitHub Pages）

手机刷题页面，题目来自：

- 9.变电检修（A）.xlsx
- 10.变电基建（A）.xlsx

## 发布到 GitHub Pages

1. 在 GitHub 新建一个空仓库。
2. 将本文件夹内的 4 个文件上传到仓库根目录。
3. 打开仓库 **Settings → Pages**，选择 **Deploy from a branch**、`main`、`/ (root)`，保存。
4. 等待约 1 分钟后，用手机打开 GitHub Pages 地址即可刷题。

页面支持顺序/随机刷题、按题库筛选、单选/多选/判断、即时判分、错题本、断点续刷和离线缓存。
